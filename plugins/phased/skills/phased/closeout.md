# Close-out (project complete)

Offer these in one question (multi-select). Do only what the user picks:

1. **Save the lesson.** Append 3–5 lines to `LESSONS.md` in the folder that holds the project folder (e.g. `~/phased/LESSONS.md`): date · project · symptom keywords · root cause or outcome (fact) · the fix · any gotcha. No secrets or client names. It is searched at planning, never loaded, so it costs nothing until it matches. If the lesson matters beyond this kind of project, also offer to save it to Claude's memory.
2. **Archive the sessions** (reversible) **or 3. delete them** (permanent; the app asks the user to confirm each). Covers this project's phase sessions and its control thread; do this session last. Pinned or on-screen sessions may be refused: list those for the user. Without the tools, list the names. PLAN.md and the handovers hold everything either way.
4. **Keep or remove the project folder**: say where it is; never delete it unasked.

Send the final `PHASED STATUS — <Project> — complete` to the control thread **before** archiving or deleting anything, then stop.
